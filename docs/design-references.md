# 个人官网设计参考

以下链接用于选择内容结构与视觉方向，不直接复制站点品牌、文案或素材。

## 实际个人网站

| 网站 | 值得参考的内容 | 适合方向 |
| --- | --- | --- |
| [Brittany Chiang](https://brittanychiang.com/) | 个人介绍、工作经历、项目和文章集中展示，信息层级清晰 | 以项目和履历为主的专业作品集 |
| [Anthony Fu](https://antfu.me/) | 开源项目、博客、演讲与个人兴趣形成完整的个人主页 | 开发者、开源作者、技术分享 |
| [Lee Robinson](https://leerob.com/) | 简介、笔记与博客为核心，内容结构简洁 | 以写作为主的轻量个人网站 |

## 初步建议

如果重点是个人介绍和项目展示，可以从 Brittany Chiang 的信息结构开始；如果需要长期写文章、维护开源项目，可以参考 Anthony Fu；如果希望尽快上线并保持维护简单，可以参考 Lee Robinson 的内容结构。

选择参考方向后，再确定配色、字体、页面数量、动效与技术方案。
